# EX No.4.1. CUT SECTION OF SOLIDS
## DATE: 22/10/2026
## Name: Sanjarika V
## Reference No.: 26016005
## AIM
To create the solid model from given drawing and section the solid model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3.16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1. First, open Autodesk Fusion 360 and create a new design. Select the Top view (XZ Plane) and click on Create Sketch to start drawing.
2. Draw one horizontal line and one vertical line through the centre point. On the horizontal line, mark two points at a distance of 35 mm on both sides of the centre. These points are used to draw the two end holes.
3. Using the Center Diameter Circle tool, draw a circle of Ø50 mm at the centre. At both marked points, draw an outer circle of R15 (Ø30 mm) and an inner circle of Ø12 mm. Give all the required dimensions using the   Sketch Dimension tool. <img width="546" height="277" alt="image" src="https://github.com/user-attachments/assets/c1ee8817-fdc1-4710-93f8-869f978927ed" />

4. Select the Line tool and draw lines to connect the two R15 circles with the centre circle on the top and bottom sides. Apply the Tangent constraint to make the lines touch the circles smoothly.
5. Use the Trim tool to remove the unwanted parts of the circles and lines. Make sure the outer shape is properly formed and the two Ø12 mm holes remain. Then click on Finish Sketch.<img width="653" height="405" alt="Screenshot 2026-11-11 213915" src="https://github.com/user-attachments/assets/17b90d0a-76d6-4f9b-bfa3-2f83d5b45512" />

6. Select the Extrude tool and choose the complete base profile, leaving the two Ø12 mm holes unselected. Set the extrusion distance to 10 mm to create the base plate.
7. Select the top face of the base plate and create a new sketch. Select the Ø50 mm circular profile at the centre and finish the sketch. Use Extrude and set the distance to 18 mm with the operation set to Join. This creates the central cylinder and gives a total height of 28 mm.
8. Select the top face of the cylinder and create a new sketch. Draw a Ø20 mm circle at the centre using the Center Diameter Circle tool. Finish the sketch and use Extrude with the Cut option. Select Through All to create the centre hole.
9. Again, select the top face and create a new sketch. Draw a Ø30 mm circle at the centre. Finish the sketch and use Extrude with the Cut option. Set the depth to 6 mm to create the counterbore.<img width="387" height="462" alt="Screenshot 2026-11-11 215110" src="https://github.com/user-attachments/assets/7b3eaf25-d32d-4402-9d3f-ef5bc516e4f1" />

10. Select the Front view (XY Plane) and click on Create Sketch. Draw a Ø6 mm circle on the vertical centre line, at a distance of 12 mm below the top of the cylinder. Click on Finish Sketch.
11. Select the Extrude tool and choose the Cut option. Extend the cut from the side hole towards the centre hole until both holes are connected. This creates the small side hole.
12. Finally, check all the dimensions, including Ø50 mm, Ø30 mm counterbore with 6 mm depth, Ø20 mm centre hole, two Ø12 mm holes, Ø6 mm side hole, R15 mm, 70 mm distance between the end holes, 10 mm base thickness and 28 mm total height. Save the completed model with the required file name.
13. Switch to the Drawing workspace and create a new drawing using the ISO standard. Insert the Top view, Front view, Right Side view and Isometric view. Add a section view of the Front view to show the internal holes clearly. Apply all the necessary dimensions, check the drawing and save the file.
